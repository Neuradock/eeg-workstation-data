# Root Figure Provenance

These figures are root-level visual demos for the repository landing page. They
are derived examples, not additional labelled data.

| Figure | Source data | Display method |
|---|---|---|
| `01-bluetooth-7channel-timeseries.png` | `example_data_bluetooth.txt` | Seven-channel Bluetooth text export parsed to `7 x samples`, 1-45 Hz filtered, vertically offset for display |
| `02-open-closed-alpha-demo.png` | `open_closed_eye2.txt` | Posterior 8-13 Hz Alpha envelope, representative low-Alpha and high-Alpha windows, and posterior PSD comparison |

The open/closed-eye figure selects low-Alpha and high-Alpha windows from the
posterior Alpha envelope in the `open_closed_eye2.txt` recording. These windows
are used as a device-performance demonstration of Alpha modulation, not as
clinical or behavioural annotations.
